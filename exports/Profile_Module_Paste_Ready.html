1 Update Profile /api/v1/profile/update PATCH ✅ Yes Update profile fields: nickname, dob, gender, height, about, attributes, discovery settings etc. 
{ "profile": { "nickname": "John", "dob": "1998-05-20", "gender": "male", "height": 175, "about": "..." }, "attributes": { "zodiac": "Leo", "interests": ["hiking"] }, "discovery": { "distanceRange": 50, "showMeGender": ["female"] } }
 200 
{ "success": true, "message": "Profile updated successfully", "data": { "user": { full profile } } }
 400, 404, 500 
{ "success": false, "message": "Profile not found" }
{ "success": false, "message": "Woman is not a valid gender option" }
 1) Profile not found → 404
2) Mongoose ValidationError → 400
3) Internal error → 500

3 Upload Photos /api/v1/profile/photos POST ✅ Yes Upload profile photos (multipart). Max 6 photos. Auto-crops to 1080x1350. First photo = primary. 
FormData: files[] (multipart/form-data)
 200 
{ "success": true, "message": "2 photo uploaded successfully", "data": { "user": { full profile } } }
 400, 500 
{ "success": false, "message": "No files uploaded" }
{ "success": false, "message": "Maximum 6 photos allowed." }
 1) No files → 400
2) Exceeds 6 limit → 400
3) Cloudinary failure → 500
4 Delete Photo /api/v1/profile/photos DELETE ✅ Yes Delete a specific photo by publicId. Re-orders remaining photos. Removes from Cloudinary. 
{ "publicId": "mafs/users/.../abc123" }
 200 
{ "success": true, "message": "photo deleted successfully", "data": { "user": { full profile } } }
 404, 500 
{ "success": false, "message": "Photo not found" }
 1) Photo not found → 404
2) Cloudinary delete fail → 500

 400, 404, 500 
{ "success": false, "message": "photoId and toPosition are required" }
