1 Claim Prize /api/v1/giveaway/claim POST ✅ Yes Claim a giveaway prize after winning the spin. Requires winHistoryId and claimEmail. Checks if user has active store subscription. Sets deliveryStatus to REVEALED. 
{
  "winHistoryId": "ObjectId",
  "claimEmail": "user@example.com"
}
 200 
{
  "success": true,
  "message": "Prize claimed successfully",
  "data": {
    "claimedAt": "ISO",
    "deliveryStatus": "REVEALED",
    "claimEmail": "user@example.com"
  }
}
 400, 404 
{ "success": false, "message": "Win ID (winHistoryId) is required" }
{ "success": false, "message": "A valid email is required" }
{ "success": false, "message": "No unclaimed prize found" }
 1) Missing winHistoryId → 400
2) Invalid email → 400
3) Already claimed → 404
2 Get Giveaway Info /api/v1/giveaway/info GET ✅ Yes Fetch giveaway landing page content. Returns brands, howItWorks steps, and importantInfo. Creates default doc if none exists. 
None
 200 
{
  "success": true,
  "data": {
    "brands": [{ "heading": "...", "subheading": "..." }],
    "howItWorks": [...],
    "importantInfo": { "heading": "...", "points": [...] }
  }
}
 500 
{ "success": false, "message": "Internal server error" }
 1) Auto-creates defaults if empty
3 Update Giveaway Info /api/v1/giveaway/info POST ✅ Yes Update giveaway landing page content. Accepts brands[], howItWorks[], importantInfo{}. Partial update supported. 
{
  "brands": [{ "heading": "Amazon", "subheading": "Gift Cards" }],
  "howItWorks": [{ "heading": "Step 1", "subheading": "Subscribe" }],
  "importantInfo": { "heading": "Note", "points": ["Point 1"] }
}
 200 
{ "success": true, "message": "Giveaway info updated successfully", "data": { ... } }
 500 
{ "success": false, "message": "Internal server error" }
 1) Partial update OK
2) Internal → 500
4 My Giveaways /api/v1/giveaway/my-giveaways GET ✅ Yes Get user's full giveaway history + spin wheel config. Returns all wins with prize details, claim status, coupon codes (if delivered). Includes spinConfig with wheel items and winnerIndex for UI animation. 
None
 200 
{
  "success": true,
  "totalWins": 2,
  "data": {
    "history": [{
      "id": "...",
      "wonAt": "ISO",
      "deliveryStatus": "DELIVERED",
      "couponCode": "ABC123",
      "prize": { "title": "...", "value": 50 },
      "campaign": { "title": "...", "drawStatus": "DRAWN" }
    }],
    "spinConfig": {
      "showSpin": true,
      "winnerIndex": 3,
      "items": [{ "label": "..." }]
    }
  }
}
 500 
{ "success": false, "message": "Failed to fetch giveaway history" }
 1) No wins → empty history[]
2) Unclaimed → showSpin: true
3) Delivered → shows couponCode
