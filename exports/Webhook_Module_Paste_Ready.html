1 Apple Webhook /api/v1/webhooks/apple POST 🔒 verifyAppleWebhook middleware Apple App Store Server Notifications V2 endpoint. Verifies JWS signedPayload via appleService.verifyAndDecodeJWS(). Deduplicates via payloadHash (unique index on SubscriptionEvent). Responds 200 immediately, processes async in background. Handles: SUBSCRIBED, DID_RENEW, DID_CHANGE_RENEWAL_STATUS, DID_FAIL_TO_RENEW (GRACE_PERIOD / billing retry), GRACE_PERIOD_EXPIRED, EXPIRED, REFUND (subscription + consumable). After processing, syncs premium state via UsageService._syncPremiumState(). 
Apple sends:
{
  "signedPayload": "eyJ...JWS_token"
}

Decoded internally contains:
- notificationType: "DID_RENEW"
- subtype: "AUTO_RENEW_DISABLED"
- notificationUUID: "uuid"
- data.signedTransactionInfo: "JWS"
 200 
"OK"

(plain text — Apple expects 200 OK)

Duplicate webhook:
"Duplicate"
 500 
"Error"

(plain text 500 response)
 1) Duplicate payloadHash (MongoDB 11000) → 200: "Duplicate"
2) JWS verification failure → 500: "Error"
3) Background processing error → logged, event.error updated with retryCount
4) webhookLimiter rate limiting applied
2 Google Webhook /api/v1/webhooks/google POST 🔒 verifyGoogleWebhook middleware Google Play Real-time Developer Notifications endpoint. Decodes base64 message.data via googleService.decodeWebhookPayload(). Handles both subscriptionNotification and oneTimeProductNotification. Deduplicates via payloadHash. Responds 200 immediately, processes async. Subscription events: PURCHASED, RECOVERED, RESTARTED, RENEWED, CANCELED, IN_GRACE_PERIOD, ON_HOLD, EXPIRED, REVOKED, PAUSED. Consumable events: CONSUMABLE_PURCHASED, CONSUMABLE_CANCELED. Syncs premium state after processing. 
Google Pub/Sub sends:
{
  "message": {
    "messageId": "msg_id",
    "data": "base64_encoded_string"
  }
}

Decoded data contains:
- subscriptionNotification: {
    "subscriptionId": "com.mafs.weekly",
    "purchaseToken": "token",
    "notificationType": 4
  }
OR
- oneTimeProductNotification: {
    "sku": "com.mafs.5superkeen",
    "purchaseToken": "token",
    "notificationType": 1
  }
 200 
"OK"

(plain text — Google expects 200)

Not subscription/product event:
"Not supported event"

"Duplicate"

"Error"

(plain text 500 response)
 1) No subscriptionNotification or oneTimeProductNotification → 200: "Not supported event"
2) Duplicate payloadHash (11000) → 200: "Duplicate"
3) Google API verify failure → logged, event.error updated with retryCount
4) webhookLimiter rate limiting applied
5) Consumable CANCELED triggers handleConsumableRefund()
