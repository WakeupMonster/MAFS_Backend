1 Import Contacts /api/v1/contacts/import POST ✅ Yes Import phone contacts. Normalizes phones, hashes them. Checks which contacts are on app and which are already blocked. 
{ "contacts": [{ "name": "John", "phone": "+614..." }] }
 200 
{ "success": true, "contacts": [{ "name": "John", "phone": "+614...", "isOnApp": true, "alreadyBlocked": false }] }
 400 
{ "success": false, "message": "No valid contacts found" }
 1) No valid contacts → 400
2 Block Contacts /api/v1/contacts/block POST ✅ Yes Block contacts by phone numbers. Accepts contacts[] or phones[] array. Normalizes, hashes, skips already blocked. 
{ "contacts": [{ "phone": "+614...", "name": "John" }] }
 200 
{ "success": true, "message": "2 contact(s) blocked successfully", "alreadyBlocked": 1 }
 400 
{ "success": false, "message": "No valid contacts provided" }
 1) No valid contacts → 400
3 Get Blocked Contacts /api/v1/contacts/blocked GET ✅ Yes Get list of all blocked contacts. Sorted by createdAt descending. Returns phone, name, source, date.
