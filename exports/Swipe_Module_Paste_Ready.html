# Sub-Module API Endpoint Method Auth Description Request Body Success Code Success Response Error Codes Error Response Error Scenarios ✏️ Improvements
1 Get Feed /api/v1/swipe/feed GET ✅ Yes Get discovery feed of potential matches. Paginated results. Requires completed profile. Uses allowDating middleware to check eligibility. 
Query: ?limit=20&page=1
 200 
{ "success": true, "message": "Feed fetched successfully", "count": 20, "data": [{ userId, nickname, age, photos, distance, ... }] }
 403, 500 
{ "success": false, "message": "Please complete your profile setup to explore matches!", "data": { "actionAllowed": false, "reason": "PROFILE_NOT_FOUND" } }
 1) Profile not created → 403: PROFILE_NOT_FOUND
2) Internal error → 500
2 Swipe Action /api/v1/swipe/action POST ✅ Yes Perform swipe: like, dislike, or superlike. Checks profile completeness and verification. Creates match if mutual like. 
{ "targetId": "userId_here", "action": "like" }
 200 
{ "success": true, "message": "It's a match!", "matched": true, "matchId": "..." }
OR
{ "success": true, "message": "Liked!", "matched": false }
 400, 403 
{ "success": false, "message": "Complete your profile to start swiping!", "data": { "actionAllowed": false, "reason": "PROFILE_INCOMPLETE" } }
{ "success": false, "message": "Verify your identity to unlock swiping", "data": { "reason": "VERIFICATION_PENDING" } }
 1) No profile → 403: PROFILE_NOT_FOUND
2) Profile incomplete → 403: PROFILE_INCOMPLETE
3) Not verified → 403: VERIFICATION_PENDING
4) Swipe error → 400
3 Unmatch User /api/v1/swipe/unmatch POST ✅ Yes Unmatch a user. Deletes match + both-side swipes in a MongoDB transaction. Emits socket event. Clears Redis feed cache. 
{ "matchId": "match_object_id" }
 200 
{ "success": true, "message": "Unmatched successfully" }
 400 
{ "success": false, "message": "Match not found or already unmatched" }
 1) Match not found → 400
2) User not part of match → 400
3) Transaction abort → 400
4 Get Matches /api/v1/swipe/matches GET ✅ Yes Get all matches. Sorted by last message then match date. Returns partner profile with conversation preview. 
None
 200 
{ "success": true, "data": { "conversations": [{ "matchId": "...", "partnerId": "...", "nickname": "Sara", "age": 25, "mainPhotoUrl": "url", "isNew": true, "lastMessage": null, "lastMessageTime": null, "matchedAt": "ISO date" }] } }
 500 
{ "success": false, "message": "Internal Server Error" }
 1) Internal error → 500
2) No matches → returns empty conversations[]
5 Undo / Rewind /api/v1/swipe/undo POST ✅ Yes Undo last swipe. Uses REWIND quota (premium feature). Reverses match if exists. MongoDB transaction-based. 
None
 200 
{ "success": true, "message": "Swipe undone successfully", "data": { "undoneAction": { "targetId": "...", "action": "like" }, "isPremium": true, "showAds": false, "premiumFeatures": {...}, "allocations": {...}, "wallet": {...} } }
 400, 403 
{ "success": false, "message": "You've reached your daily Rewind limit!" }
{ "success": false, "message": "No swipe found to undo" }
 1) REWIND limit reached → 403
2) No swipe to undo → 400
3) Transaction error → 400
6 Get Keen (Likes) /api/v1/swipe/keen GET ✅ Yes Get users who liked you (excluding already swiped). Paginated. Shows distance, city, age, photo. 
Query: ?page=1&limit=20
 200 
{ "success": true, "data": [{ "userId": "...", "nickname": "Sara", "age": 24, "mainPhotoUrl": "url", "distanceText": "5 km away", "city": "Delhi", "action": "like", "likedAt": "ISO date" }], "meta": { "total": 15, "page": 1, "limit": 20, "hasMore": false } }
 500 
{ "success": false, "message": "Server Error" }
 1) No likes → returns empty data[]
2) Internal error → 500
