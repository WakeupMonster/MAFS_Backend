# Sub-Module API Endpoint Method Auth Description Request Body Success Code Success Response Error Codes Error Response Error Scenarios ✏️ Improvements
1 Send Message /api/v1/chat/:matchId/message POST ✅ Yes Send a text message in a matched conversation. Updates Match lastMessage and lastMessageTime. Sends push notification to partner. 
{ "text": "Hey, how are you?" }
Params: matchId
 201 
{ "success": true, "data": { "_id": "msg_id", "matchId": "...", "senderId": "...", "text": "Hey, how are you?", "type": "text", "createdAt": "ISO date" } }
 400, 403, 404 
{ "success": false, "message": "Match not found" }
{ "success": false, "message": "You are not part of this match" }
{ "success": false, "message": "Text is required" }
 1) Match not found → 404
2) Not part of match → 403
3) Empty text → 400
4) Socket emit to partner in real-time
2 Get Messages /api/v1/chat/:matchId/messages GET ✅ Yes Get paginated messages for a match conversation. Sorted by newest first. Cursor-based pagination using before parameter. 
Query: ?limit=30&before=msg_id
Params: matchId
 200 
{ "success": true, "data": [{ "_id": "...", "senderId": "...", "text": "Hello!", "type": "text", "createdAt": "ISO date", "readBy": ["userId"] }], "meta": { "hasMore": true, "nextCursor": "msg_id" } }
 403, 404 
{ "success": false, "message": "Match not found" }
{ "success": false, "message": "You are not part of this match" }
 1) Match not found → 404
2) Not part of match → 403
3) No messages → returns empty data[]
3 Chat List /api/v1/chat/list GET ✅ Yes Get all active chat conversations for current user. Returns partner info, last message preview, unread count, and online status. 
None
 200 
{ "success": true, "data": [{ "matchId": "...", "partner": { "userId": "...", "nickname": "Sara", "mainPhoto": "url", "isOnline": true }, "lastMessage": { "text": "Hey!", "senderId": "...", "createdAt": "ISO date" }, "unreadCount": 3 }] }
 500 
{ "success": false, "message": "Failed to fetch chat list" }
 1) No chats → returns empty data[]
2) Internal error → 500
4 Mark Read /api/v1/chat/:matchId/read POST ✅ Yes Mark all messages in a conversation as read. Updates readBy array for all unread messages from partner. 
Params: matchId
 200 
{ "success": true, "message": "Messages marked as read" }
 403, 404 
{ "success": false, "message": "Match not found" }
 1) Match not found → 404
2) Not part of match → 403
3) Emits socket read receipt event
5 Delete Message /api/v1/chat/:matchId/message/:messageId DELETE ✅ Yes Delete a specific message. Only sender can delete their own messages. Soft delete — marks as deleted, doesn't remove from DB. 
Params: matchId, messageId
 200 
{ "success": true, "message": "Message deleted successfully" }
 403, 404 
{ "success": false, "message": "Message not found" }
{ "success": false, "message": "You can only delete your own messages" }
 1) Message not found → 404
2) Not the sender → 403
3) Socket emit for real-time delete
6 Upload Media /api/v1/chat/:matchId/media POST ✅ Yes Upload image/video in chat. Uploads to Cloudinary. Creates message with type "image" or "video". Max file size enforced by multer. 
FormData: media (single file)
Params: matchId
 201 
{ "success": true, "data": { "_id": "msg_id", "matchId": "...", "senderId": "...", "type": "image", "mediaUrl": "cloudinary_url", "createdAt": "ISO date" } }
 400, 403, 404 
{ "success": false, "message": "No media file uploaded" }
{ "success": false, "message": "Match not found" }
 1) No file → 400
2) Match not found → 404
3) Not part of match → 403
4) Cloudinary upload fail → 500
7 Delete Media Message /api/v1/chat/:matchId/media/:messageId DELETE ✅ Yes Delete a media message. Removes media from Cloudinary and soft-deletes the message from conversation. 
Params: matchId, messageId
 200 
{ "success": true, "message": "Media message deleted successfully" }
 403, 404 
{ "success": false, "message": "Message not found" }
{ "success": false, "message": "You can only delete your own messages" }
 1) Message not found → 404
2) Not the sender → 403
3) Cloudinary destroy + DB soft delete
